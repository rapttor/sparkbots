# SparkBots press kit

Everything you need to write about SparkBots: ready-to-edit articles, original artwork and a screenshot shot list.
Project: https://github.com/rapttor/sparkbots

SparkBots is a local, browser-based 3D "office" for AI coding agents. Every Claude Code, Codex or OpenCode session is a small robot at a desk, every project is a team area. It runs on your machine and nothing leaves it.

No web fonts. Use the system stack everywhere, in the artwork and in text:

```
-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif
```

Wordmark: "Spark" in the text colour, "Bots" in teal, bold, tight letter spacing, written as one word with a capital B.

## Logo do and don't

Do
- Use `logo-dark.svg` on dark backgrounds and `logo-light.svg` on light ones; `logo.svg` is transparent for dark surfaces.
- Keep clear space around the logo of at least the width of the visor.
- Use `logo-mark.svg` or `favicon.svg` when space is small (avatars, tabs).
- Write the name as "SparkBots".

Don't
- Don't stretch, rotate, recolour the visor to a non-palette colour, or add shadows and outlines.
- Don't write it as "Spark Bots", "Sparkbot" or "SPARKBOTS" in running text.
- The robots are SparkBots' own drawings of how it shows a Claude, Codex or OpenCode session. Don't put them next to, or inside, any other company's logo, and don't redraw them to look like another product's mascot.
- Don't use the robots or the names under them to imply endorsement by an AI vendor. The names only say which tool a robot stands for.
