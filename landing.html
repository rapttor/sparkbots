The project

Awareness for people who run too many agents.

Terminals give you tabs and scrollback, not a picture of what is going on. SparkBots reads the session history your agents already write and turns it into a small office you can look at: sleeping robots are your history, glowing ones are live work, an amber beacon means someone is waiting for you. It is a personal tool first, so it is local, private and a little silly on purpose. It never edits your sessions and never uses permission-bypass flags.

Done

  • 3D campus with a robot per session, rooms and an avatar or hand to move around
  • Claude Code, Codex, OpenCode adapters, read-only on your history
  • Chat with live replies, fork, new robot, allow-and-retry for a denied tool
  • Kanban board that sends cards to agents, plus a Backlog.md lane
  • Usage stats per service, kept forever in local SQLite
  • Data center, coffee factory, game room, gym, restaurant

Planned

  • Live permission approval inside the chat
  • Slash commands and skills in the chat box
  • Cubicles with trophy shelves for each agent
  • More games: billiards, basketball, claw machine, a race track
  • Opt-in sync between machines, off unless you configure it
  • MCP servers per project in the server room
